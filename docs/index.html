官方原生内置

URL Context（url_context）

默认关闭，需在请求 tools 中传入 types.Tool(url_context=types.UrlContext())。采用两步检索（先查 Google 内部索引缓存，未命中则实时抓取），支持 HTML/JSON/PDF/GitHub 仓库。阅读的页面内容计入模型输入。
